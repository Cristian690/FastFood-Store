# FastFood Store

Aplicación web desarrollada con HTML, CSS, TypeScript y Vite.

---

## Descripción

FastFood Store es un catálogo de productos con sistema de carrito de compras utilizando renderizado dinámico y almacenamiento local del navegador mediante localStorage.

El proyecto fue realizado como trabajo práctico para la materia Programación 3.

---

## Funcionalidades

- Visualización dinámica de productos
- Búsqueda en tiempo real
- Filtro por categorías
- Agregado de productos al carrito
- Persistencia de datos con localStorage
- Visualización de cantidades agregadas
- Cálculo automático del total
- Vaciar carrito
- Reset del carrito desde el catálogo
- Diseño responsive básico

---

## Tecnologías utilizadas

- HTML5
- CSS3
- TypeScript
- Vite
